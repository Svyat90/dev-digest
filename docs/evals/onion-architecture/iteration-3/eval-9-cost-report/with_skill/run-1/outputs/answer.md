Прочитав `onion-architecture/SKILL.md`, `references/audit.md`, `server/INSIGHTS.md` (записи 2026-09-19 про null/0 та `sum()`), я розібрав модуль `cost-report`. Прохід «Queries» (6): `service.report` викликає `repo.costForDay` у вкладених циклах агент × день. На 90 днях це N_агентів × 90 окремих SQL-запитів послідовно, тобто N+1 (service.ts, цикли `for agent`/`for i`). Прохід «Output»/доменне правило: `repository.ts` робить `Number(row?.total ?? 0)`. Це перетворює NULL («немає даних») на 0, а в `AgentCost.days.costUsd` тип `number`, тож UI не може показати «—» і малює $0.00. INSIGHTS прямо забороняє це: `null` = unknown, `0` = free, а агрегати йдуть через `parseAggregateCost`. Також `totalUsd`/`perDayAvgUsd` рахуються з цих нулів, а середнє ділиться на `days`, а не на дні з даними. Додатково (структура, не блокер): запит по днях через `gte/lt` на `Date` залежить від UTC-меж, а `from` береться як довільна дата, не нормалізована до початку доби; route будує `new CostReportRepository` сам (прийнятно в plugin body, але відповіді немає `response`-схеми, тому тип `AgentCost` не є контрактом). Tenancy в порядку (`workspaceId` у кожному запиті), імпорти по кільцях чисті (service не імпортує drizzle). Виправлення, кроками (кожен лишає `arch:check` зеленим): 1) замінити `costForDay` на один метод `costByAgentDay(workspaceId, from, to)` у repository: один `SELECT agent_id, date_trunc('day', ran_at) AS day, sum(cost_usd) ... GROUP BY 1,2` з фільтром `workspace_id` і діапазоном, а `listAgents` винести з циклу (вже ззовні); 2) у repository віддавати `costUsd: number | null` через `parseAggregateCost`, без `?? 0`; 3) у service (чиста функція в `helpers.ts`) заповнити пропущені дні значенням `null`, `totalUsd` суми лише ненульових (або `null`, якщо даних немає взагалі), `perDayAvgUsd` ділити на кількість днів із даними; 4) додати `costUsd: number | null` у тип/контракт, оголосити `response: { 200: Schema }` на route, а в UI рендерити `null` як «—»; 5) тест: unit на чисту функцію заповнення днів (null vs 0) і `*.it.test.ts` на агрегат із днем без запусків.
